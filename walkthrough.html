📋 AliExpress Purchased Orders APIs (Date Range & Order ID)
TOP Protocol Sync RPC

Enables dropshippers and merchants to retrieve orders placed by their authenticated AliExpress account. Includes date-range filtering, automated pagination, start/end boundary expansions, 180-day safety guards, and single-order detail lookups.

1
Get Orders by Date Range
Queries orders within a specified window. Converts dates to YYYY-MM-DD HH:mm:ss, applies start-of-day (00:00:00) and end-of-day (23:59:59) boundaries, and enforces the platform 180-day window limit.
GET /api/aliexpress/orders?startDate=...&endDate=...
2
Get Order by ID
Retrieves full order specifications via aliexpress.trade.ds.order.get. Extracts order status, payment timestamp, child items, recipient address, and tracking numbers.
GET /api/aliexpress/orders/:orderId
3
Auto-Pagination Engine
The getAllOrdersByDateRange helper automatically queries consecutive pages and aggregates all matching orders, strictly bound by a maxPages safety limit to eliminate infinite loops.
--all flag / fetchAll=true

🔐 AliExpress OAuth 2.0 & Singapore Gateway Architecture
Gateway: api-sg.aliexpress.com

Global AliExpress Open Platform applications operate via the Singapore gateway (api-sg.aliexpress.com), distinct from the legacy domestic Taobao gateway. The application handles the full token lifecycle automatically.

1

OAuth Authorization URL

Directs user to https://api-sg.aliexpress.com/oauth/authorize with client_id, redirect_uri, and response_type=code.

2

Authorization Code Redirect

User logs in and AliExpress redirects to your configured callback URI with a temporary authorization code parameter.

3

Cryptographic Token Exchange

Backend signs a POST /auth/token/create request with HMAC-SHA256, exchanging the code for an access_token and refresh_token.

4

Auto-Refresh & Persistence

Tokens are saved in .token.json. Subsequent requests check expiration and automatically renew tokens before they expire via /auth/token/refresh.

HMAC-SHA256 Cryptographic Signing Algorithm (src/core/signer.ts) 
export function generateAliExpressSignature({ appSecret, apiName, params }: SignOptions): string {
  // 1. Exclude 'sign' and null/undefined values
  const validEntries = Object.entries(params).filter(
    ([key, val]) => key !== "sign" && val !== undefined && val !== null
  );

  // 2. Sort parameter keys in ascending ASCII order
  validEntries.sort(([a], [b]) => (a < b ? -1 : a > b ? 1 : 0));

  // 3. Prepend REST path if applicable (/auth/token/create)
  let baseString = apiName.includes("/") ? apiName : "";
  for (const [key, val] of validEntries) {
    baseString += `${key}${String(val)}`;
  }

  // 4. Compute HMAC-SHA256 uppercase hexadecimal digest
  return crypto.createHmac("sha256", appSecret)
    .update(baseString, "utf8")
    .digest("hex")
    .toUpperCase();
}
